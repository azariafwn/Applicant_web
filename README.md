# 🌐 LearningApplicantWeb - Sistem Manajemen Pelamar

![ASP.NET Core](https://img.shields.io/badge/ASP.NET%20Core-512BD4?style=for-the-badge&logo=dotnet&logoColor=white) ![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white) ![Entity Framework](https://img.shields.io/badge/Entity%20Framework-4E245D?style=for-the-badge) ![DataTables.js](https://img.shields.io/badge/DataTables-134273?style=for-the-badge&logo=datatables&logoColor=white)

**LearningApplicantWeb** adalah sebuah aplikasi web yang dibangun menggunakan ASP.NET Core MVC untuk mengelola data pelamar (applicants). Proyek ini dirancang sebagai platform untuk mempraktikkan dan mendemonstrasikan implementasi aplikasi web *end-to-end* dengan arsitektur yang bersih dan fitur antarmuka yang modern.

## ✨ Fitur Utama

Aplikasi ini dilengkapi dengan beberapa fitur unggulan yang meningkatkan fungsionalitas dan pengalaman pengguna:

#### 🎨 **UI Modern & Responsif dengan Template Velzon**
Dibangun di atas **Velzon**, sebuah template admin & dashboard premium, aplikasi ini memiliki antarmuka yang:
* **Modern dan Bersih**: Tampilan profesional yang mengikuti tren desain terkini.
* **Sepenuhnya Responsif**: Dapat diakses dengan baik di berbagai perangkat, mulai dari desktop hingga mobile.
* **Kaya Komponen**: Memanfaatkan komponen UI siap pakai untuk konsistensi dan pengembangan yang lebih cepat.

#### 🎛️ **Tabel Data Interaktif dengan DataTables.js**
Seluruh tabel data di dalam aplikasi ini ditenagai oleh **DataTables.js**, sebuah *plug-in* jQuery yang andal. Ini memberikan fitur-fitur canggih secara otomatis tanpa perlu *coding* tambahan pada sisi *frontend*, seperti:
* **Pencarian Cepat (Live Search)**: Filter data secara instan di seluruh isi tabel hanya dengan mengetik.
* **Pengurutan Kolom (Sorting)**: Urutkan data berdasarkan kolom mana pun (abjad, angka, tanggal) dengan sekali klik.
* **Paginasi (Paging)**: Navigasi data dalam jumlah besar dengan mudah melalui halaman-halaman yang terorganisir.
* **Kustomisasi Tampilan**: Mengatur jumlah data yang ingin ditampilkan per halaman.

#### 🗄️ **Manajemen Data (CRUD)**
Aplikasi mendukung operasi Create, Read, Update, dan Delete untuk mengelola data pelamar secara efisien.
